# 🚀 دليل مهندس المزوّدين — ابدأ من هنا

مرحبًا 👋 — ده كل اللي محتاج تعرفه عشان تضيف مزوّد (Provider) جديد للـGateway.
اقرأه مرة واحدة من الأول للآخر (١٥ دقيقة)، وبعدها هتقدر تبني أي مزوّد.

---

## 1) إيه ده أصلًا؟ (الصورة الكبيرة في ٣٠ ثانية)

الـ**Gateway** ده خدمة وسيطة بين "المنصة" (Platform) و"المزوّدين الحقيقيين"
(زي Groq، OpenAI، أي API خارجي). المنصة **ماتعرفش** أي حاجة عن المزوّد؛ هي بس
بتبعت طلب موحّد للـGateway، والـGateway بيوصّله للمزوّد الصح ويرجّع رد موحّد.

**شغلك أنت:** تكتب "المزوّد" — الكود اللي بياخد الطلب الموحّد، يكلّم الـAPI
الخارجي الحقيقي، ويرجّع الرد بالشكل الموحّد.

**المهم:** أنت بتشتغل في مكان واحد بس (`providers/<اسم_مزوّدك>/`)، و**عمرك
ماهتلمس** أي حاجة في الـ`gateway/` نفسه ولا في المنصة. ده مضمون بالتصميم.

```
المنصة  ──طلب موحّد──►  الـGateway  ──►  مزوّدك (أنت)  ──►  API خارجي حقيقي
المنصة  ◄──رد موحّد───  الـGateway  ◄──  مزوّدك (أنت)  ◄──  API خارجي حقيقي
```

## 2) القاعدة الذهبية — الطبقات الثلاث (أهم فكرة في الملف كله)

مزوّدك مكوّن من ٣ طبقات. افهمهم كويس:

### 🟢 الطبقة ١ — الداخل (حرّيتك الكاملة)
ده الكود اللي بيكلّم الـAPI الخارجي. **إنت حرّ ١٠٠٪ هنا:**
- أي عدد ملفات (ملف أو ٣٠ ملف)
- أي مكتبة/SDK
- أي طريقة مصادقة (API key / OAuth / session / cookies)
- عدة حسابات، rotation، caching، أكتر من نداء للـAPI، fallback داخلي...

**كله مخفي تمامًا** عن الـGateway وعن المنصة. اكتب اللي يعجبك.
> اصطلاح: سمّي ملفات الطبقة دي ببادئة شرطة سفلية `_` (زي `_upstream.py`)
> عشان الـGateway يتجاهلها ولا يحاول يعاملها كنقطة دخول.

### 🟡 الطبقة ٢ — الواجهة (`adapter.py`) — الحدّ الإلزامي الوحيد
ده **المترجِم**. الطبقة الوحيدة اللي الـGateway بيشوفها. مهمتها:
- تاخد طلب موحّد (`ProviderContext`)
- تنادي طبقتك الداخلية (الطبقة ١)
- تترجم الناتج لـ**واحد من اتنين بس**:
  - ✅ نجاح بالشكل الموحّد المطلوب للـoperation
  - ❌ خطأ من الـ**١٢ نوع** المعرّفة (مفيش شكل تالت)

**ممنوع** مزوّدك يخترع شكل رد خاص بيه ويسيب الـGateway "يفهمه". الـ`adapter.py`
هو اللي لازم يترجم للشكل الموحّد **قبل** ما أي حاجة تعبر الحدّ.

### 🔵 الطبقة ٣ — العقد (`gateway.contracts`) — ثابت، ماتغيّرهوش
ده الشكل الموحّد للطلب والرد وأنواع الأخطاء. **بتستورده بس، عمرك ما تعدّله.**
هو واحد لكل المزوّدين في الدنيا.

```
    مزوّدك (أنت)
 ┌─────────────────────┐
 │ الطبقة ١: الداخل     │  ← حرّ تمامًا (أي ملفات/SDK/auth)
 │ _upstream.py ...     │
 └──────────┬──────────┘
      adapter.py          ← الطبقة ٢: المترجِم الإلزامي
            │
            ▼
   gateway.contracts       ← الطبقة ٣: العقد الثابت
            │
            ▼
         المنصة
```

**الجملة اللي تحفظها:** "طلب واحد للـGateway ← أي شغل داخلي مهما كان معقّد ←
رد موحّد واحد."

## 3) أول حاجة تعملها — شغّل المشروع وشوفه بيمشي

محتاج Python 3.11+ .

```bash
cd gateway-service

# ثبّت الاعتماديات (بيئة افتراضية موصى بها)
python3 -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"

# شغّل كل الاختبارات — لازم كلها تعدّي (أخضر)
python3 -m pytest
```

لو كل الاختبارات عدّت ✅ يبقى البيئة سليمة وإنت جاهز.

> ملاحظة: الاختبارات كلها **hermetic** — يعني مش بتلمس الشبكة خالص، بتستخدم
> ردود وهمية (mock). ده مقصود عشان تشتغل بسرعة وأمان في أي مكان.

## 5) اعمل مزوّدك خطوة بخطوة (وصفة عملية)

يلا نعمل مزوّد اسمه `acme` كمثال.

### الخطوة ١ — انسخ القالب
```bash
cp -r providers/_template providers/acme
```
> ماتحطّش شرطة سفلية `_` في اسم مزوّدك — المجلدات اللي بتبدأ بـ`_`
> (زي `_template` و`_example`) الـGateway بيتجاهلها ولا يسجّلها.

### الخطوة ٢ — املأ `providers/acme/definition.py` (الإعلان)
ده "بطاقة تعريف" مزوّدك. الـGateway بيثق في الإعلان ده بس — **مش** في الكود.
أعلن **بس** اللي بيشتغل فعلًا.

مثال حقيقي (من Groq):
```python
DEFINITION: dict[str, object] = {
    "display_name": "Groq",              # الاسم الوحيد اللي بيعبر للمنصة
    "definition_version": "1.0.0",        # semver — زوّده مع أي تغيير
    "credential_mode": "platform",        # "platform" أو "user_key" (شرح تحت)
    "capabilities": {"chat": True, "reasoning": True, "code": True},
    "operations": ["generate_text"],      # بس اللي ليه handler في adapter.py
    "models": [
        {"name": "llama-3.1-8b-instant", "context_window": 131072},
    ],
    "health_supported": False,            # False = ردّ /v1/health بأمانة "UNKNOWN"
}
```

قواعد لازم تحترمها (وإلا الخدمة مش هتشتغل من أول تشغيل):
- كل operation في `operations` **لازم** يكون ليه handler في `adapter.py`،
  والعكس. أي عدم تطابق = **فشل عند التشغيل** (حماية مقصودة).
- **ممنوع** تعلن `run_provider_agent` / `upload_asset` / `download_asset` —
  دي مستبعدة من النسخة ١ (ADR-0008)، وأي إعلان ليها **بيترفض عند التحميل**.
- operation مش مدعومة = **متعلنهاش خالص** (مش stub فاضي). الإعلان نفسه = الأهلية.
- `capabilities` مفاتيحها من مجموعة مقفولة (`gateway.contracts.CAPABILITY_KEYS`).
- `models: []` مقبولة وصادقة لو مفيش موديلات.

### الخطوة ٣ — اكتب طبقتك الداخلية (الطبقة ١، حرّة)
اعمل ملف زي `providers/acme/_client.py` فيه نداء الـAPI الحقيقي. استخدم اللي
تحبه. (شوف `providers/groq/_upstream.py` كمثال حقيقي — بيستخدم httpx.)

### الخطوة ٤ — اكتب الواجهة `providers/acme/adapter.py` (الطبقة ٢)
لكل operation معلن، اكتب handler بياخد `ProviderContext` ويرجّع `FacadeResult`.
شكله العام (مبسّط من Groq):
```python
from gateway.contracts import (
    ErrorCategory, FacadeResult, GatewayOperation, ProviderContext, Usage,
)
from gateway.errors import make_error
from providers.acme._client import call_acme_api   # طبقتك الداخلية

async def generate_text(context: ProviderContext) -> FacadeResult:
    # 1) تحقّق من المدخلات (شكل الـpayload في docs/CONTRACT.md §1)
    # 2) نادِ طبقتك الداخلية (الطبقة ١)
    # 3) نجاح؟  ارجع الشكل الموحّد للـoperation + Usage
    #    فشل؟   ارجع make_error(ErrorCategory.<النوع الصح>, ...)
    ...

# الـGateway بيتأكد إن مفاتيح HANDLERS == operations في definition.py
HANDLERS: dict[GatewayOperation, object] = {
    GatewayOperation.GENERATE_TEXT: generate_text,
}
```
> افتح `providers/_template/adapter.py` — فيه **كل الـ8 operations** موثّقة
> سطر-بسطر: كل واحدة بتاخد إيه بالظبط، لازم ترجّع إيه بالظبط، وإزاي تحوّل
> الأخطاء. ده مرجعك الأساسي.

### الخطوة ٥ — سجّل مزوّدك
في `app.py` فيه دالة `register_live_providers`. ضيف سطر يسجّل مزوّدك
(زي سطر Groq الموجود بالظبط). ده كل التسجيل المطلوب.

### الخطوة ٦ — اكتب اختبارات hermetic
اعمل `tests/providers/test_acme.py`. استخدم mock للـAPI الخارجي (متلمسش
الشبكة). لازم تغطّي: شكل النجاح الموحّد، تحويل الأخطاء، وعدم تسريب أي أسرار.
شوف `tests/providers/test_groq.py` كمثال جاهز.

### الخطوة ٧ — شغّل الاختبارات
```bash
python3 -m pytest
```
كله أخضر؟ 🎉 مزوّدك جاهز.

## 6) الأنواع الـ١٢ للأخطاء (احفظها — لازم تحوّل أي فشل لواحد منها)

| النوع | امتى | قابل لإعادة المحاولة؟ |
|---|---|---|
| `auth_expired` | المفتاح/الجلسة كانت صح وانتهت (ممكن تتجدّد) | نعم |
| `invalid_credential` | المفتاح غلط أو ملغى | لأ |
| `rate_limited` | الـAPI رجّع 429 (تجاوزت الحد) — حُطّ `retry_after_ms` | نعم |
| `quota_exceeded` | خلص رصيدك/حصتك | لأ |
| `model_unavailable` | الموديل المطلوب مش موجود | لأ |
| `provider_unavailable` | الـAPI واقع/مش موصول | لأ |
| `unsupported_capability` | العملية/الميزة مش مدعومة | لأ |
| `bad_request` | مدخلات المستخدم غلط | لأ |
| `content_rejected` | رفض بسبب سياسة أمان/محتوى | لأ |
| `timeout` | الـAPI عدّى وقت المهلة | نعم |
| `retryable_server_error` | الـAPI رجّع 5xx مؤقت | نعم |
| `non_retryable_error` | أي حاجة تانية دائمة | لأ |

خريطة HTTP الشائعة (زي ما Groq عاملها): `401/403 → invalid_credential` ·
`404 → model_unavailable` · `429 → rate_limited` · `400/413/422 → bad_request` ·
`5xx → retryable_server_error` · `timeout → timeout`.

## 7) المصادقة (المفاتيح) — نمطين بس

في `definition.py` بتختار `credential_mode`:

- **`"platform"`** — المفتاح بتاعك إنت (مثلًا مفتاح شركتك لـGroq). بتحلّه
  **جوّا طبقتك الداخلية** (مثلًا من متغيّر بيئة). المنصة **عمرها ما تعرفه**.
  ← ده اللي Groq بيستخدمه: المفتاح من متغيّر بيئة، والواجهة عمرها ما بتشوفه.

- **`"user_key"`** — مفتاح المستخدم نفسه (BYOK). بيوصلك في الطلب
  (`context.credential_value`)، تستخدمه في الذاكرة وبس، **ماتخزّنوش ولا
  تسجّله في أي log**.

## 8) قواعد أمان صارمة (متكسرهاش أبدًا)

- **ماتسجّلش (log) أبدًا:** المفاتيح، التوكنات، قيم BYOK، الـ`route_token`،
  الاسم الداخلي (slug)، أو رابط الـAPI الخارجي.
- مزوّدك **مايشوفش** الـ`route_token` ولا الـslug ولا مصدر الطلب الحقيقي —
  بيشوف `ProviderContext` بس. كده هو مقصود.
- **كن صادقًا (never-fake):** متـرجّعش نجاح مفبرك. لو الصحة غير معروفة، قول
  `UNKNOWN`. لو عملية مش مدعومة، متعلنهاش. الصدق شرط أساسي في المشروع ده.
- **صفر إعادة محاولة (retry) على مستوى الـGateway** في النسخة ١ — عشان
  محاسبة الاستخدام تفضل دقيقة. (أي منطق داخلي عندك يخضع للقاعدة دي.)

---

## 9) ممنوعات (خطوط حمراء)

- ⛔ متعدّلش أي حاجة في `gateway/` (محرّك الـGateway) — اقراه للفهم بس.
- ⛔ متعدّلش `docs/CONTRACT.md` ولا `gateway/contracts.py` (العقد ثابت).
- ⛔ متلمسش مجلد مزوّد تاني — كل واحد في فولدره.
- ⛔ متعملش endpoint عام لتسجيل مزوّدين — التسجيل من `app.py` بس.
- ⛔ متعلنش عملية من غير handler، ولا تكتب handler من غير إعلان.

---

## 10) خلاصة نهائية

1. انسخ `providers/_template/` باسم مزوّدك.
2. املأ `definition.py` بصدق (أعلن اللي بيشتغل بس).
3. اكتب طبقتك الداخلية (حرّ) + `adapter.py` (المترجِم).
4. سجّله في `app.py`.
5. اكتب اختبارات hermetic.
6. `pytest` أخضر = خلصت.

**مرجعك وقت الشك:** `docs/CONTRACT.md` (العقد) + `providers/groq/` (مثال حقيقي)
+ `providers/_template/adapter.py` (موثّق سطر-بسطر).
